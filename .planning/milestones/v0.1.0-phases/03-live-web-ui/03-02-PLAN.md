ROADMAP Goal (not in user-story form; surfaced for review, no story invented per the MVP rules): "The developer watches and drives a running bench from a local web page that is a pure client of the same API the CLI uses."

This plan finishes the phase tracer of 03-01 on the page side and builds the browser test harness every later plan verifies against.
