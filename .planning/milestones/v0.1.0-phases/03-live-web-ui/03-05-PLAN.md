## Phase Goal

ROADMAP Goal (not in user-story form; surfaced for review, no story invented): "The developer watches and drives a running bench from a local web page that is a pure client of the same API the CLI uses."

This plan makes the LAN default of D-07 safe enough to keep (D-08's cheap protections) and gives the developer the reach controls of D-09: a phone on the LAN opens the URL `sil up` prints, and a page the developer visits elsewhere cannot drive the bench. Together with 03-03 (connection and stream limits) it completes success criterion 1 on the server side.

<objective>
Give `sil up` the reach flags (--listen, --web-port, --allow-host, --ui-dir) with Phase 1's sticky-port conflict rules and the URL output, then put the web listener behind a Host allowlist, CSRF and WS origin checks and security headers.

Purpose: UI-01 server half; D-07, D-08 (cheap protections, unauthenticated notice in `sil up`), D-09.
Output: UpCmd flags, UpOptions and Spec fields, PortRequest, stderr URL line, web.Guard, host_rejected and origin_rejected codes, e2e TestWebReach.
</objective>
