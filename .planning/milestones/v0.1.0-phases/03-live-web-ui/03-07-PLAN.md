## Phase Goal

ROADMAP Goal (not in user-story form; surfaced for review, no story invented): "The developer watches and drives a running bench from a local web page that is a pure client of the same API the CLI uses."

The page must have no logic of its own, so three things it needs are built in the engine and reach every client through the API and the CLI first: the plot history (D-12, criterion 2), the behind-real-time flag (criterion 4) and the stuck-hold guard (D-15, criterion 3). Each task is one slice that ends in a `sil` command an agent can use today; 03-10 and 03-11 put them on the page.

Purpose: D-12, D-15, UI-05's behind warning, UI-06 (every new value and action is CLI-reachable).
Output: events.SampleKind/Sample/HistoryCap/Broker.History, engine sample emission, behind-real-time and max-hold, control History types and DownRequest, the history Operations row, supervisor/history.go, `sil history`, `--max-hold`, e2e TestHistory/TestBehindField/TestMaxHold.
</objective>
