ROADMAP Goal (not in user-story form; see 01-01-PLAN.md note). Purpose: proves the simulator half of the architecture (Unix-socket bus server, actor engine, model, fan library, injectable clock) against real firmware before the CLI layers are put in front of it in 01-03.

3. internal/bus: codec.go implements Frame/Encode/Decode as in `<interfaces>` with a lenient flat-object decoder (string and number values only, `\"` and `\\` escapes, error on nesting; 01-06 makes it strict). The number accessors are what keeps duty exact: GetF32 is the wire float32; GetNum re-expresses that float32 as its shortest decimal parsed at float64, so a firmware duty 0.4f reads as exactly 0.4 (not 0.4000000059604645) and the engine, status and every exact duty assertion agree with the commanded decimal. 4. internal/engine (single-writer actor, D-02): Run listens via bus.Listen(cfg.BusPath), closes Ready, starts the accept loop, and runs one select loop over the inbox (bus frames and connect/disconnect events), a 10 ms clock ticker and ctx. Each tick: dt = now - last, every port state = model.Step(port.Fan, state, duty, dt), publish a new Snapshot through atomic.Pointer. An out frame on `portN.duty` sets that port's duty from GetNum (clamped to [0,1]); frames apply in arrival order. On a `hello` frame reply `welcome` with proto 1 and t = sim time in microseconds, then one `in` frame per port with the current rpm. Every 50 ms of sim time send `in` frames `portN.rpm` (v = rpm, t = sim µs) for ports whose float32 rpm changed since the last send. Ports come from cfg.Ports (four in Phase 1). Unknown kinds and channels are ignored (01-10 turns them into warnings).
