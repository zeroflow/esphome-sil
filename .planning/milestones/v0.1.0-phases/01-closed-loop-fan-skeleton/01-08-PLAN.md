## Phase Goal

ROADMAP Goal (not in user-story form; see 01-01-PLAN.md note). This plan delivers criterion 1's build half (pinned image, static binary, no root-owned files, clean tree) and criterion 5's build half (host-incompatible components stop the build with a message naming the problem).

Purpose: BUILD-01, BUILD-02, BUILD-03, BUILD-06 (reboot_timeout assertion), D-15..D-18.
Output: internal/fwbuild (pipeline, lint, cache, elf) with unit tests and bench-level e2e tests.
</objective>
