# API Coverage — ESPHome native API (firmware `api:` component, Noise-encrypted)

> Full coverage by default. Opt-outs are explicit, reasoned decisions.
> Scope: Phase 1 consumes the ESPHome native API in two places only — the `sil serve` readiness probe (`internal/apiclient`, plan 01-09) and the e2e test client (`e2e/api_client.py`, aioesphomeapi inside the pinned image, plan 01-01). The simulator is deliberately not an API proxy: Home Assistant and aioesphomeapi talk to the firmware directly (ARCHITECTURE Anti-Pattern 9). The `sil` control API (`/api/v1/*` on `api.sock`) is this project's own surface, not an external integration.
