## Accomplishments

- Tracer: five stub headers plus `test_txcap.cpp` compile the real `components/sim_bus/sim_bus.cpp` by path with `-Wall -Wextra -Werror`. The drop fires after about 1200 `set_out` calls with 65541 bytes pending; pending never exceeds `kMaxTx` (65536) while connected (max 65485).

## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 3 - Blocking] component.h stub lacked `<cstdint>`**
- **Found during:** Task 2 (`make test-cpp-image`, gcc 14.2)
- **Issue:** `sim_bus.h` uses `uint32_t` without including `<cstdint>`; host g++ 12 got it transitively, gcc 14 did not, so the image build failed. The real ESPHome `component.h` provides it, so the stub was less faithful than intended (threat T-03.1-08).
- **Fix:** the stub includes `<cstdint>` with a comment saying why. The product header was left untouched.
- **Files modified:** `tests/cpp/stubs/esphome/core/component.h`
- **Verification:** `make test-cpp-image` and `make test-cpp` both `txcap: 63 passed, 0 failed`
- **Committed in:** `fb28319`
