## Concurrency invariants re-derived

Each item: verdict, then the code it rests on (`supervisor.go` unless stated; line numbers are the file after plan 03.1-02).

1. **Lock order `opMu -> inMu -> mu`.** Holds. Acquiring call sites:
   - `opMu`: `shutdown` (l.464), `autoRestart` (l.647), `SimRestart` (l.801), `FwRestart` (l.1283). `stopAll` is called with `opMu` held (or before any operation can run).
   - `inMu`: `run` (l.273, then `mu` inside at 279-281), `SimRestart` (l.828, released at 831/848/857, with `mu` taken inside it), `Set` (l.1199). `startEngine` takes none; its callers hold `inMu`.
   - `mu` only, never held while taking another lock: `Status`/`statusFrom`, `isStopping`, `currentEngine`, `endEngGap`, `stopAll`'s first section, `recordExit`, the probe setters.
   - `Press`/`SetButton` take no supervisor lock beyond `mu` via `currentEngine`.
   - Nothing takes `inMu` while holding `mu`, and nothing takes `opMu` while holding `inMu`. Verdict: holds.
2. **`engGap` lifecycle.** Holds. Set under `mu` at l.815 before `stopEngine(old)` (l.820), so a Set can only observe `ErrStopped` from the old engine after the flag is up. Cleared in one `mu` section together with the slot install (l.845-856), on a failed start (l.837), on an aborted gap sleep (`endEngGap`), and by the deferred `endEngGap` (l.819) on any other exit. A Set that read `engGap == true` holds `inMu`, which `SimRestart` also needs before `startEngine` (l.828), so a gap Set is always recorded before the next engine is seeded (`startEngine` copies `s.inputs`/`s.fans` at l.356-357). No lost update and no flag that outlives the restart.
3. **`Apply` on `withDown(context.WithoutCancel(ctx))` cannot hang a Set forever.** Holds. `Engine.Apply` returns on the reply, on `e.done` (engine stopped) or on its context (`engine.go` Apply, after the `e.done` pre-check). The context is cancelled by `withDown` when `downReq` closes. `stopEngine`/`stopAll` take no `inMu`, so a Set blocked inside `Apply` under `inMu` is released when the engine is cancelled. The only unbounded wait left is `inMu.Lock()` itself (F4).
4. **`engDied` is not raised for an engine SimRestart cancels.** Holds. `startEngine` sends on `engDied` only when `up.Load() && ctx.Err() == nil`; `stopEngine` cancels first (l.385-390).
5. **Record equals engine after quiescence.** Holds for the paths the tests exercise, and is pinned by `TestSetAndSimRestartKeepRecordAndEngineEqual` (Task 2) under `-race`.
