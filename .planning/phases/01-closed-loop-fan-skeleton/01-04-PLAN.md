  <behavior>
    - Now() starts at 0 and only moves on Advance
    - A 10 ms ticker fires exactly 100 times during Advance(1 s), in order, each value equal to its due time
    - A timer fires once at its due time; Stop before the due time prevents it and returns true
    - Sleep(ctx, d) returns nil after Advance passes d and returns ctx.Err() when ctx is cancelled first
    - BlockUntil(n) returns once n tickers/timers/sleepers are registered
    - Deadline returns the zero time.Time
    - WithTimeout(parent, m, 2 s): ctx.Done not closed after Advance(1999 ms); closed after Advance(1 ms) more, with TimedOut(ctx) true
    - WithTimeout's CancelFunc called before the due time: ctx done, TimedOut false, and Advance(5 s) afterwards returns (the timer was stopped or drained)
    - Parent cancelled before the due time: child done, TimedOut false, and Advance(5 s) afterwards returns
  </behavior>
  <action>
manual_test.go first (RED), then manual.go (GREEN): Manual implements clock.Clock. Waiters (tickers, timers, sleepers) live in a mutex-protected list sorted by due time; Advance(d) repeatedly takes the earliest waiter due at or before now+d, sets now to its due time and delivers the value with a blocking send on an unbuffered channel (tickers re-arm at due+period), then sets now to the target; Stop removes the waiter and returns true, or returns false when Advance already took it (its value is then being delivered, which is what lets 01-01's WithTimeout drain after a false Stop); BlockUntil(n) waits on a sync.Cond until at least n waiters exist; Deadline returns time.Time{}. The file lives in internal/clock, the one directory the wall-clock lint skips, but it must not read the wall clock either: Manual time comes only from Advance (MODEL-04).
