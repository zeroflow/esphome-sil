## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| TCP port (0.0.0.0:<port>) -> sil probe | anything listening on the port may answer the handshake |
| shared /tmp -> run dir fallback | other local users can pre-create paths in /tmp |
| $XDG_STATE_HOME/sil -> identity files | key material at rest |
