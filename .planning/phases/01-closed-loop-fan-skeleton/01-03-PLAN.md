## Phase Goal

ROADMAP Goal (not in user-story form; see 01-01-PLAN.md note). Third and last link of the Walking Skeleton tracer chain (`SKELETON.md`): the developer runs `sil up`, `sil status` and `sil down` and gets the closed loop from 01-02 with firmware built as in 01-01.

<objective>
Put the `sil` CLI in front of the proven loop: `sil up` creates the instance identity and run dir, builds the firmware, detaches a `sil serve` supervisor that owns the firmware process and the engine, and waits until the firmware is on the bus; `sil status` reads the control API over a Unix socket; `sil down` stops everything.

Purpose: completes the walking skeleton (process model, detach, control API, CLI JSON contract) end to end; every wave-4 plan expands one of these packages without changing the contracts in `<interfaces>`.
Output: cmd/sil, internal/{cli,lifecycle,instance,supervisor,control}, e2e Env helpers, TestTracer.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| local user -> sil CLI | instance names and paths from argv/env become filesystem paths and docker arguments |
| other local processes -> api.sock / bus.sock | Unix sockets in the run dir; api.sock serves the API key in status |
| identity dir at rest | the API key lives in identity.json |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-01 | Tampering | instance.ValidateName / PathsFor | high | mitigate | Regex `^[a-z0-9]([a-z0-9-]{0,25}[a-z0-9])?$` before any path or argv use; exec.Command with arg slices only, never a shell |
| T-01-03 | Information disclosure | control.Serve (status carries the key) | high | mitigate | Control API only on api.sock, chmod 0600 inside the 0700 run dir; no TCP listener in Phase 1 (A3) |
| T-01-06 | Denial of service | orphaned firmware after supervisor death | medium | mitigate | Firmware started with Setpgid + Pdeathsig SIGKILL from a LockOSThread goroutine; signal handler stops the firmware group before exit |
