## Phase Goal

ROADMAP Goal (not in user-story form; surfaced for review, no story invented): "The developer watches and drives a running bench from a local web page that is a pure client of the same API the CLI uses."

The LAN default of D-07 means any machine on the network can open connections to the bench. This plan makes sure a slow, sleeping or misbehaving client can neither exhaust the listener nor take the stream slots the CLI needs, so `sil watch` and `sil logs --follow` keep working while pages are open. It is the connection half of success criterion 1's server side; 03-05 adds the Host, Origin and header rules.

<objective>
Serve the web listener through web.Limit (connection cap, header deadline from the injected clock) and web.Serve (keep-alives off, graceful shutdown), then give /ws ping-based reaping and a browser share of the stream slots.

Purpose: UI-01 server half (a LAN-facing listener that stays available); D-07 (LAN default kept safe to keep); D-08's "cheap protections that cost no UX".
Output: web.Limit, web.ListenerOptions, web.Serve, WS ping and the 8-stream browser cap, listener and WS tests, the supervisor wiring.
</objective>
