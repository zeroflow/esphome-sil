## Phase Goal

ROADMAP Goal (not in user-story form; surfaced for review, no story invented): "The developer watches and drives a running bench from a local web page that is a pure client of the same API the CLI uses."

Success criterion 1 says the page works with the network blocked and uses vendored libraries, no runtime CDN. This plan brings the one third-party library of the phase, uPlot 1.6.32, into the repository once, with recorded and re-checked hashes, so the scope screens of 03-10 load it from the sil binary. It also aligns the UI-SPEC with the stack facts the research measured, before the plot code relies on them.
