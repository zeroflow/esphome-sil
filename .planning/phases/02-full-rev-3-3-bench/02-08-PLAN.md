| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |

| T-02-20 | Spoofing / Tampering | native API reachable at lan_host | medium | mitigate | the Noise PSK stays mandatory (Phase 1 lint asserts api.encryption); README states the port is on the LAN, needs the key and should be firewalled on shared networks and CI runners |
| T-02-21 | Information disclosure | api.lan_host and the key in status / up output | low | accept | status is served only on the 0600 api.sock; the key was already in status and the up JSON in Phase 1; the LAN address is not secret on a local bench |
| T-02-22 | Information disclosure | LANHost UDP probe | low | accept | a UDP connect to a documentation address (192.0.2.1) sends no packet and reveals nothing off-host |
| T-02-SC | Tampering | npm/pip/cargo installs | low | mitigate | No new Go modules (go.mod/go.sum unchanged, verified in the acceptance run); the Python lock is re-checked with `make lock-check` |
