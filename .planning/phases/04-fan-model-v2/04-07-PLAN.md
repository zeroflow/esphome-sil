## Phase Goal

ROADMAP Goal (not in user-story form; surfaced for review, no story invented per the MVP rules): see 04-01-PLAN.md. <objective>

</objective>

- **File count (11, above the 10-file warning, kept):** both tasks are page-only and share index.html and the store/ring flow. Splitting them would leave two one-task plans that edit the same template in sequence.
- **Pattern analogs:** 04-PATTERNS.md section "store.js, plot.js, app.js" (store cases, the stepped duty series as the model for the tach series, KINDS, the parity sessionSteps rows) and "Test pinning" (uitest runs on the shipped library on purpose). Per "Plan file-name mapping": ring.js, index.html, app.css and view.js → their own existing code (fixed-width readouts, the NONE glyph); uitest/plot_test.go, parity_test.go, layout_test.go and bench_test.go → their own existing tests.
- **No UI-SPEC (A-NOUISPEC, flagged):** the layout contract is given by the acceptance criteria and the extended layout tests. The page keeps the Phase 3 rules: system font stack, no build step, no external reference, uPlot instances and rings outside any reactive state, fixed widths for values.
- **Null glyph (D-16 as amended 2026-11-11, user decision; A-GLYPH resolved):** the three new readouts show the em dash `—` whenever they have no value, and every other readout keeps NONE `--`. Mechanism: the null text belongs to the format. view.js already declares `EM_DASH = "\u2014"` for the LED captions; move it up next to NONE. Add a map `NULL_TEXT` from format name to its null text, with tach, flow and watt mapping to EM_DASH. shown() returns `NULL_TEXT[el.dataset.fmt] ?? NONE` in its no-value branches (no snapshot yet, a missing or null value). The tach readout therefore gets its own format `tach` (same text as rpm), so the RPM readout and the other existing readouts are untouched. The template placeholders of the three new readouts are `—` as well, so nothing flips between `--` and `—` at the first paint.
- **Axis (RESEARCH Pitfall 7):** quantisation and ripple can put a tach value one step above max_rpm. The axis stays fixed (no autoscale); uPlot clips at the plot area. The ring keeps the reported value unchanged.
- **Human check at end of phase** (workflow.human_verify_mode = end-of-phase): the look of the stepped trace is a visual judgment, collected in the verify block, not as a blocking checkpoint.
- **Wall-clock lint covers uitest:** use sysClock, clock.WithTimeout and the existing wait helpers.
