1. internal/model/fan.go: restructure Step around an unexported `advance(p Params, s State, duty float64, dt time.Duration) (State, Integral)` and make Step return advance's State. `Integral` is an exported struct with two fields: `Area float64`, the exact ∫ rpm dt over the step in rpm·s (rpm times seconds, so revolutions = Area/60), and `MovingS float64`, the seconds of the step with rpm > 0. advance:
   - dt <= 0 returns s and a zero Integral. Duty clamp (NaN gives 0) and the sticky direction are unchanged from 04-01.
   - Running and duty < MinDuty: running = BelowMin == "hold" (stop is immediate, D-11) and StartElapsed = 0.
   - Not running and duty >= StartDuty (at or above, D-11 as amended 2026-11-11; keep the v0.1.0 operator, never `>`): if s.StartElapsed + dt >= StartDelay, the step splits at pre = StartDelay − s.StartElapsed (clamped to >= 0): segment 1 of length pre runs stopped (target 0), segment 2 of length dt − pre runs running, and StartElapsed = 0. Otherwise the whole step is stopped and StartElapsed += dt.
   - Not running and duty < StartDuty: StartElapsed = 0.
   - Between the thresholds the previous state is kept (hysteresis follows duty).
   - A segment of length 0 is never applied (no snap in it). With StartDelay 0 every start is therefore one segment, exactly the v0.1.0 order.
   - Per segment, the target is 0 when not running, else the curve At(duty) of 04-01.
   - Per segment, the tau: TauUp when target > rpm; when target < rpm, TauDown if running, else CoastTau when > 0, else TauDown (the legacy zero value, D-09).
   - Per segment, the rpm update keeps the v0.1.0 exponential expression unchanged, including its degenerate branch (tau <= 0 gives rpm = target), followed by the v0.1.0 snap (target == 0 and rpm < 0.5 gives 0).
   - Per segment, the Area adds target·h + (rpm0 − target)·tau·(1 − e^(−h/tau)) for h seconds (rpm·h when target == rpm or tau <= 0). For a segment that snapped, integrate only up to t* = tau·ln(rpm0/0.5) clamped to [0, h]. MovingS adds h while rpm0 > 0 or target > 0, t* for a snapped segment, and 0 for a fan at rest with target 0.
   - Rewrite the Step doc comment as the schema 2 semantics list: curve target by direction, start delay with the split, immediate stop, coast tau, never-stops form, snap. The zero values of the schema 2 fields reproduce v0.1.0.
