## Phase Goal

ROADMAP Goal (not in user-story form; surfaced for review, no story invented per the MVP rules): "A simulated fan behaves like a real one: separate up and down duty→RPM curves, distinct start and stop thresholds with start delay and coast-down, a tach that quantises and jitters like the firmware's `pulse_counter` window, and airflow and power from datasheet values. All of it is driven by an explicit `fan.toml` schema 2 with per-value provenance, while every v0.1.0 fan file still behaves exactly as before."

This plan is the phase's tracer: one schema 2 fan file goes through the loader, the model and the engine to `sil status` and the firmware, before anything else is built on that path.

<objective>
Make a `schema = 2` fan file with separate up and down duty→RPM curves drive a port end to end: strict schema 2 loading with per-value provenance (fanlib), a curve-driven model behind one `model.Plant` seam, and the engine stepping that plant. Schema 1 files keep their exact v0.1.0 targets through a synthesised legacy curve.

Purpose: MODEL-05 (up and down curves, monotone, interpolated) and the schema 2 entry of MODEL-08, on the single code path every later plan of this phase (start delay, tach, noise, airflow, page, shipped library) builds on.
Output: model curve + Plant, fanlib schema probe + v2 loader, engine on Plant, a schema 2 test fixture, engine and e2e tests.
</objective>

	MinDuty      float64
	StartDuty    float64
	BelowMin     string // "stop" or "hold"

func Initial(p Params) State                       // Running: p.BelowMin == "hold"
func Step(p Params, s State, duty float64, dt time.Duration) State
// running target today: duty < MinDuty (hold only) -> MinRPM; else

// snap: if target == 0 && rpm < 0.5 { rpm = 0 }

Every present value has exactly one entry. An entry key that is not a present value fails with "provenance entry <key> names no value of this file". An entry value is `kind` or `kind:source_id`: kind must be in model.Kinds, and source_id must be a key of [sources]. Anything else is an error that names the entry. Provenance never defaults.
