## Phase Goal

ROADMAP Goal (not in user-story form; surfaced for review, no story invented per the MVP rules): see 04-01-PLAN.md. This plan delivers the `sil fans` half of criterion 5 (schema version and the provenance of every value) and hardens the schema 2 loader (MODEL-08).

<objective>
Make `sil fans` show each fan's schema and the provenance of every value end to end: JSON with counts and a per-value map on stdout, a summary per fan (and every value with --verbose) on stderr. Then harden the schema 2 loader: errors located inside their own table, range caps, the [tach], [datasheet] and [measured] tables, an explicit `schema = 1`, and the v1 code moved into its own file unchanged.

Purpose: MODEL-12 and the strictness part of MODEL-08 (D-05..D-08).
Output: FanInfo additions with one builder, the supervisor and CLI wiring, a stderr renderer, e2e coverage, and the loader hardening with table-driven located error tests.
</objective>
